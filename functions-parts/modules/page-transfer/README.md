# page-transfer — перенос сторінок між сайтами (тимчасовий модуль)

Переносить **вміст одного запису** (сторінки або CPT) з локалі на прод: усі поля
ACF-конструктора, мініатюру, терміни таксономій і **самі файли зображень**.
Файли їдуть усередині пакета, тож продові не потрібен доступ до `*.local`.

## Як користуватись

1. **Локал** → редактор сторінки → метабокс «Перенос сторінки» → **⬇ Експорт (.zip)**.
   (або *Інструменти → Перенос сторінок → 1. Експорт*)
2. **Прод** → *Інструменти → Перенос сторінок → 2. Імпорт*: обрати запис-приймач,
   вибрати .zip, поставити галочки що оновлювати → **⬆ Імпортувати**.

Приймач має вже існувати. Тип запису бажано той самий (інакше буде попередження).

## Що всередині пакета

`page.json` + `media/*` — файли зображень.

| Ключ | Що це |
|---|---|
| `post` | заголовок, слаг, вміст редактора, уривок, статус, шаблон |
| `meta` | вся мета запису «як є» (ACF-значення + `_`-посилання на field-ключі) |
| `types` | тип ACF-поля для кожного ключа — щоб на приймачі знати, де ID медіа |
| `attachments` | вкладення: імʼя файлу, alt, підпис, mime, sha1 |
| `post_refs` | звʼязки на інші записи (`post_object`/`relationship`) — тип + слаг |
| `terms` | терміни таксономій по слагах |
| `thumbnail` | ID мініатюри (мапиться на нове вкладення) |

Не переносяться: `_edit_lock`, `_edit_last`, WPML/Polylang-звʼязки, мета кошика.

## Що робить імпорт

1. Заливає зображення в медіатеку. Дублікатів не буде: файли зіставляються за
   **sha1** (`_delta_pt_hash` у меті вкладення) — повторний імпорт перевикористає
   вже залите.
2. Мапить старі ID вкладень на нові в усіх полях (`image`, `file`, `gallery`)
   та в HTML-контенті (URL міняються разом із розмірами `-300x200`).
3. Мапить `post_object`/`relationship` за **слагом** у межах типу. Якщо на
   приймачі такого запису немає (напр. форми CF7) — поле лишиться порожнім,
   про це буде попередження у звіті.
4. Міняє домен вихідного сайту на домен приймача в усіх рядках.
5. **Чистить стару ACF-мету приймача** перед записом — щоб не лишились «хвости»
   від довших репітерів/флексібла.

## Обмеження

- Ліміт завантаження на проді (`upload_max_filesize`) має бути більшим за розмір
  пакета — розмір ліміту показано під полем файлу.
- Якщо на сервері немає `ZipArchive`, експорт віддасть `.json` із файлами в
  base64 (важчий, але робочий) — імпорт розуміє обидва формати.
- Перезапис незворотний: перед імпортом у непорожній запис зроби бекап бази.

## Вимкнути / видалити

```php
define('DELTA_PAGE_TRANSFER', false); // wp-config.php — сховати UI
```

Повністю: видалити цей каталог і рядок `include` у `functions.php`.
